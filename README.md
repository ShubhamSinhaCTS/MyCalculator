# MyCalculator - Frontend

This repository now contains a simple frontend to perform basic arithmetic operations.

Usage

- Open index.html in a browser (double-click or serve via a static server).
- Select an operation from the dropdown, enter two numbers, and click Calculate.

Files added

- index.html - simple UI
- style.css - styling
- script.js - client-side logic

Feel free to ask me to wire this into a build step, GitHub Pages, or to add more operations or multiple inputs.
